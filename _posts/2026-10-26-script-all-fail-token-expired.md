> 근거 표기: **조회** = 이 테넌트 화면·PowerShell·Graph에서 직접 읽은 값 / **문서** = Microsoft Learn / **확인 불가** = 시도했으나 확인하지 못함(시도 방법·사유·다음 방법 병기). 계정·테넌트 식별자는 게시하지 않았다.

## 요약

| 항목 | 내용 |
|---|---|
| 증상 | 여러 항목을 한 번에 읽는 스크립트의 결과가 **전부 "측정 불가"(실패)**, 오류 문구는 Unauthorized 계열 |
| 먼저 나눈 것 | 실패가 항목마다 제각각인가, 전부 같은 모양인가 |
| 원인 | 토큰 만료로 판단(재연결 후 같은 스크립트가 정상 동작). 만료 시각은 확인하지 않음 |
| 대처 | 다시 연결하고 재실행. 남은 실패 메시지는 Forbidden / 세션 미접속 / 값 변환 오류로 묶어 따로 처리 |
| 결과 | **조회**: 재연결 뒤 전 항목 정상. 유형별로 처리 방법이 다름 |

## 전체 기록

### 1. 증상

- 한 번에 여러 항목을 읽는 스크립트를 돌렸더니 결과가 전부 "측정 불가"(실패)로 나왔습니다. 항목마다 다른 원인이 아니라 **전부 같은 모양**이었습니다(조회).
- 오류 문구는 "Unauthorized" 계열이었습니다.

### 2. 먼저 확인할 것

실패의 모양부터 봅니다.

| 결과 | 가능성이 큰 원인 |
|---|---|
| 항목별로 제각각 실패 | 항목마다 다른 권한·환경 문제 |
| **전부 동시에 같은 모양으로 실패** | **공통 원인**(로그인·토큰) |

이번에는 공통 원인 쪽이었습니다. 개별 항목의 원인을 따로 찾기 전에 **연결 상태부터** 확인하면 시간을 아낄 수 있습니다.

### 3. 시도와 결과

**3-1. 전부 실패: 토큰 만료**

토큰 만료로 판단했습니다. 다시 연결한 뒤 같은 스크립트가 정상 동작했기 때문입니다(조회). 토큰이 정확히 언제 만료됐는지는 확인하지 않았습니다.

```powershell
# 다시 연결(필요한 범위를 명시). Cloud Shell 등에서 대화형 동의가 어려우면 환경에 맞는 로그인 방법을 쓴다.
Connect-MgGraph -Scopes "Directory.Read.All","Policy.Read.All"
```

> 위 범위는 예시입니다. 실제로 읽는 항목에 필요한 범위를 확인해 맞춥니다.

**3-2. 재연결 뒤에도 남은 실패: 유형별로 묶기**

한 번 실행에서 남은 실패 메시지는 크게 세 가지였습니다. **유형이 다르면 처리가 다릅니다.**

| 메시지 | 뜻 | 처리 |
|---|---|---|
| `Response status code does not indicate success: Forbidden (Forbidden)` | **토큰의 Graph 범위나 Entra 역할이 부족**(사람의 권한이 아님) | 필요한 범위·역할을 확인하고 동의, 안 되면 같은 값을 읽는 **화면 경로**로 대체 |
| `Session is not established`(Teams 미접속 등) | 해당 서비스에 **연결하지 않고** 명령을 실행 | 서비스별 연결 명령을 먼저 실행(예: Teams는 `Connect-MicrosoftTeams`) |
| `Cannot convert null to type "System.DateTime"` 등 | **스크립트가 값 형태를 가정**했는데 어긋남 | 값이 없거나 배열일 때의 처리를 추가 |

### 4. 대처와 원복

- 다시 연결하고 재실행했습니다. 스크립트 안내문에도 "전 항목이 Unauthorized로 나오면 토큰 만료이니 재연결 후 재실행"을 적어 두었습니다.
- 읽기 전용 조회였으므로 되돌릴 설정 변경은 없습니다.
- 유형별 후속 글
  - Forbidden: [Cloud Shell 토큰으로 되는 Graph 호출과 안 되는 호출]({{ "/m365/troubleshooting/cloud-shell-graph-token-scope/" | relative_url }})
  - 세션 미접속: [명령이 모듈 없음·환경에 따라 접속 안 됨]({{ "/m365/troubleshooting/powershell-module-not-found/" | relative_url }})
  - 값 변환 오류: [빈 값(null)에서 계산 오류·누락]({{ "/m365/troubleshooting/null-values-in-scripts/" | relative_url }})

### 5. 운영에서는 이렇게 판단한다

1. **실행 전**: 연결 상태(토큰 만료 여부), 서비스별 연결, 필요 범위·역할을 확인합니다.
2. **결과를 받으면**: 전부 같은 모양으로 실패했다면 공통 원인(연결·토큰)부터 봅니다.
3. **실패 메시지**는 Forbidden / 연결 없음 / 값 변환 오류로 묶어서 처리합니다.
4. **읽지 못한 항목**은 비워 두지 말고 "확인 불가 + 시도한 방법 + 사유 + 다음 방법"으로 남깁니다.
