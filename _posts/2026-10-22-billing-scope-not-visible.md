Azure 구독의 청구 계정 유형과 청구 역할을 확인하려고 비용 관리 + 청구를 열었더니 청구 범위 목록이 비어 있었고(0건), 둘 다 확인 불가로 남았습니다. 청구 역할을 받는 것은 보안 변경이라 권한을 올려서 뚫지 않고, 어디까지 읽었고 무엇이 남았는지를 기록했습니다.

## 요약

- 비용 관리 + 청구의 청구 범위 목록이 "입력한 필터와 일치하는 항목이 없습니다"로 비어 있음
    - 접근 가능한 청구 범위 0건, 청구 프로필 없음, 청구 계정 1개(유형 칸이 비어 있음)
- 원인은 확인 불가. 후보는 두 가지
    - 청구 범위에 접근할 권한이 없음
    - 개발자 프로그램 구독이라 EA/MCA 청구 계정 범위가 보이지 않는 구조(추정)
- 청구 역할을 부여받는 것은 보안 변경이라 하지 않음. 청구 담당자에게 확인할 일로 남김
- 청구 계정 유형, 내 청구 역할, 결제 수단 필요 여부는 확인 불가
    - "추가 구독을 만들 수 있는가"는 판단 불가, 측정 판독은 측정 불가로 남김

> 근거 표기: 조회 = 이 테넌트에서 직접 읽은 값, 문서 = Microsoft Learn, 확인 불가 = 시도했지만 확인하지 못한 값(방법과 사유 병기). 테넌트 ID, 도메인, 계정, 사용자 이름 등 비공개 정보는 가리거나 게시하지 않았습니다. 구독 ID도 게시하지 않았습니다.

---

## 전체 기록

### 1. 증상

GUI에서 Azure 포털 > 비용 관리 + 청구 > 청구 범위로 들어가면 목록이 "입력한 필터와 일치하는 항목이 없습니다"로 비어 있습니다. 조회 값은 접근 가능한 청구 범위 0건, 청구 프로필 없음, 청구 계정 1개(유형 칸이 비어 있음)였습니다.

같은 조회를 사전 환경 점검(10/19)에서 한 번, 운영 설정 실측(10/22)과 10/23에 다시 했고 모두 0건이었습니다.

![청구 범위 목록이 비어 있는 Azure 비용 관리 + 청구 화면]({{ "/assets/images/2026/10/billing-scopes-empty.png" | relative_url }})
*그림 1. 비용 관리 + 청구 > 청구 범위. 표 머리글(청구 범위, 범위 유형, 청구 계정, 계정 유형, 내 역할, 상태) 아래가 비어 "입력한 필터와 일치하는 항목이 없습니다"만 보입니다. 계정과 디렉터리 식별 표시는 가렸습니다.*

### 2. 원인과 대처

원인 후보는 둘로 좁혔지만, 구조 원인은 확인하지 못했습니다.

- 청구 범위에 접근할 권한이 없습니다.
- 개발자 프로그램 구독은 EA/MCA 청구 계정 범위가 보이지 않는 구조로 보인다(**추정**).

청구 범위에 접근하려면 역할을 부여받아야 하는데, 이는 보안 변경이라 하지 않았습니다. 가이드의 안내대로 추가 구독을 만들 수 없으면 내부에 알려야 하므로 확인 사항으로 올렸습니다. 바꾼 설정이 없으니 원복할 것도 없습니다.

### 3. 다음에 청구 범위가 0건으로 나오면

청구 범위가 0건이라는 건 "청구 담당이 없다"가 아니라 **내 계정에서는 값이 보이지 않는다**는 뜻일 수 있습니다. 그래서 "0건"을 "문제 없음"으로 적지 않고 측정 불가로 적습니다.

구독 Owner라고 해서 청구 범위까지 읽을 수 있다고 가정하지도 않습니다. 이 구독에서는 Owner인데도 0건이었습니다.

비용이 나갈 수 있는 구독(지출 한도 Off)이라면 청구 담당과 청구 역할을 먼저 알아 두는 것이 운영 인수 때 확인할 일입니다. 청구 역할을 직접 받아서 뚫는 건 측정이 아니라 권한 변경이므로, 담당자에게 묻는 길을 먼저 씁니다.

### 4. 확인 과정

<details markdown="1">
<summary>확인 과정 자세히 보기</summary>

#### 나눠 본 순서

청구 범위가 비어 있는 이유를 아래 순서로 나눠 보았습니다.

1. **구독이 어떤 유형인가**
    - 읽은 값(조회): QuotaId = PayAsYouGo_2014-09-01(종량제), 구독 1개, 상태 Enabled
    - 해석: 개발자 프로그램이 만든 종량제 구독
2. **구독에서 내 역할은 무엇인가**
    - 읽은 값(조회): Owner(구독 범위, 영구 활성). Owner가 하나 더 있고 서비스 사용자임
    - 해석: 구독 Owner인데도 청구 범위는 0건
3. **청구 범위, 프로필, 계정이 보이는가**
    - 읽은 값(조회): 범위 0건, 프로필 없음, 계정 1개(유형 비어 있음)
    - 해석: 계정은 있으나 유형과 역할이 화면에 나오지 않음
4. **지출 한도**
    - 읽은 값(조회): Off(문서에도 종량제 구독에는 지출 한도 기능이 없다고 있음)
    - 해석: 청구 범위와는 별개의 값

#### 시도와 결과

| 시도 | 결과 | 판단 |
|---|---|---|
| 비용 관리 + 청구에서 청구 범위 목록 열기 | 0건("입력한 필터와 일치하는 항목이 없습니다") | 화면에서 더 읽을 값이 없음 |
| 같은 조회를 다른 날 반복 | 여전히 0건 | 결과가 같음 |
| 청구 계정 유형, 내 청구 역할 읽기 | 읽지 못함 | **확인 불가** |
| 결제 수단 필요 여부 읽기 | 읽지 못함 | **확인 불가** |
| 추가 Azure 구독 생성 가능 여부 판단 | 근거가 되는 값을 읽지 못함 | **판단 불가**로 남김 |

</details>

### 5. 확인 불가로 남은 것

<details markdown="1">
<summary>확인 불가 항목 펼쳐 보기 (5건)</summary>

- **청구 계정 유형**
    - 시도 방법: 청구 범위와 청구 계정 조회
    - 막힌 이유: 범위 0건, 계정 유형 칸이 비어 있음
    - 다음 방법: 청구 담당자에게 확인
- **내 청구 역할**
    - 시도 방법: 청구 범위 조회
    - 막힌 이유: 청구 범위에 접근할 권한이 없고, 역할을 부여받는 것은 보안 변경이라 하지 않음
    - 다음 방법: 청구 담당자에게 확인
- **결제 수단 필요 여부**
    - 시도 방법: 청구 범위 조회
    - 막힌 이유: 위와 같음
    - 다음 방법: 청구 담당자에게 확인
- **추가 구독 생성 가능 여부**
    - 시도 방법: 위 값들로 판단
    - 막힌 이유: 근거 값을 읽지 못함
    - 다음 방법: 위 확인 뒤 판단
- **EA/MCA 청구 범위 역할(구조 원인)**
    - 시도 방법: 청구 범위 목록 조회
    - 막힌 이유: 개발자 프로그램 구독은 EA/MCA 범위가 보이지 않는 구조로 보이나 원인은 확인하지 못함
    - 다음 방법: EA/MCA 계정이 있는 운영 테넌트에서 청구 범위의 액세스 제어 확인

</details>
