10/28 10:00에 만들어 둔 개인 일정 `zz-test-personal-event`가 검색해도, 월 보기로 봐도 보이지 않았습니다. 지운 적이 없어 원인은 확인 불가로 두고, 같은 이름·같은 시각으로 다시 만들어 경위를 남겼습니다.

## 요약

- 사라진 일정은 같은 이름과 시각으로 다시 만들고 그 경위를 기록함
- 증거 화면은 만든 직후 선명하게 남기고 시험 일정은 정리 목록에 넣으면 됨
- 일정이 사라진 원인은 확인 불가이며 추정으로 채우지 않음

> 근거: 조회는 이 테넌트에서 직접 읽은 값, 문서는 Microsoft Learn입니다. 비공개 정보는 가렸습니다.

---

## 전체 기록

### 1. 증상

- Outlook 웹(`outlook.office.com` → 캘린더 → 주 보기/월 보기)에 10/28 10:00 개인 일정 `zz-test-personal-event`가 없음
- 검색(`zz-test`) 0건, 월 보기 10월 전체 비어 있음, 지운 작업 없음

### 2. 원인 및 분석

보기 설정, 검색, 필터, Graph 순서로 봤지만 일정은 없었고, Graph로는 달력 소유자까지만 확인했습니다.

<details markdown="1">
<summary>확인 과정 자세히 보기</summary>

1. 보기 설정 때문인가: 주 보기와 월 보기를 모두 열었습니다. 10/28에 일정이 없었고, 월 보기에서 10월 전체가 비어 있었습니다.
2. 검색으로 찾을 수 있는가: 제목의 공통 부분(`zz-test`)으로 검색해 0건이었습니다.
3. 필터가 일정을 가리고 있는가: 필터는 "예약"만 꺼져 있어 원인이 아니었습니다.
4. Graph로 읽을 수 있는가: `/me/events`는 Calendars 범위가 없어 403이었습니다. Calendars.Read를 동의한 토큰으로 달력을 조회(`GET /me/calendar`)하자 200 OK가 나왔고, 달력 소유자는 사용자 계정이었습니다(조회). 사라진 원인은 이 조회로도 확인하지 못했습니다.

</details>

### 3. 결론

`화면·검색·Graph 어디에도 없음 + 지운 기록 없음 → 단서 없음 → 확인 불가, 다시 만듦`

원인은 확인 불가입니다(시도: 2절 네 가지 / 사유: 일정도 지운 기록도 없어 단서 없음). 지금은 같은 이름·시각으로 다시 만든 일정이 있습니다.

<details markdown="1">
<summary>다시 만든 과정 보기 (그림 1장)</summary>

**GUI 경로**: Outlook 웹 → 캘린더 → 새 이벤트 → 제목 `zz-test-personal-event`, 날짜 2026-10-28, 시작 오전 10:00(끝 10:30) → 저장 → 주 보기에서 확인.

### 4. 권고방안

1. 조치: 원인을 모르면 추정으로 채우지 말고 확인 불가로 적은 뒤 다시 만든 경위를 남깁니다. 증거 화면은 만든 직후 남기고, 시험 일정은 정리 목록에 넣습니다.
2. 조치 후 확인: 주 보기 10/28(수) 10:00에 일정이 보이면 됩니다. 또 사라지면 Calendars.Read 토큰으로 일정 목록을 제목 조회해 비교합니다.
