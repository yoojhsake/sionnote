> 근거 표기: **조회** = 이 테넌트 화면·PowerShell에서 직접 읽은 값 / **문서** = Microsoft Learn / **확인 불가** = 시도했으나 확인하지 못한 값(시도 방법·사유·다음 방법 병기). 계정 부분은 가렸고 사용자 이름은 적지 않았습니다.

## 요약

| 항목 | 내용 |
|---|---|
| 증상 | 10/28 10:00에 Outlook 웹에서 만들어 둔 개인 일정 `zz-test-personal-event`가 보이지 않음. 검색(`zz-test`)도 0건, 월 보기에서도 10월 전체가 비어 있음 |
| 원인 | **확인 불가.** 이 일정을 지운 작업은 한 적이 없음 |
| 대처 | 같은 이름·같은 시각으로 GUI에서 다시 만들고 경위를 기록 |
| 결과 | 개인 캘린더 10/28(수) 10:00에 일정이 다시 보임 |

---

## 전체 기록

### 1. 증상

일정 저장 위치를 설명하는 그림을 선명하게 다시 찍으려고 Outlook 웹(`outlook.office.com` → 캘린더 → 주 보기/월 보기)을 열었더니, 10/28에 개인 일정이 **없었습니다**. 일정 검색(`zz-test`)도 0건이었고, 월 보기에서도 10월 전체가 비어 있었습니다.

이 일정을 지운 작업은 한 적이 없습니다.

### 2. 먼저 확인할 것

1. **보기 설정 때문인가.** 주 보기와 월 보기를 모두 열어 봅니다.
2. **검색으로 찾을 수 있는가.** 제목의 공통 부분(`zz-test`)으로 일정을 검색합니다.
3. **필터가 일정을 가리고 있는가.** 캘린더 필터를 확인합니다. 필터는 "예약"만 꺼져 있어 원인이 아니었습니다.
4. **Graph로 읽을 수 있는가.** `/me/events`는 토큰에 Calendars 범위가 없으면 403이라 처음에는 쓰지 못했습니다([개인 달력이 403일 때]({{ "/m365/troubleshooting/personal-calendar-403-calendars-read/" | relative_url }})).

### 3. 시도와 결과

| 시도 | 결과 |
|---|---|
| 주 보기·월 보기 | 10/28에 일정 없음, 월 보기에서 10월 전체가 비어 있음 |
| 일정 검색(`zz-test`) | 0건 |
| 필터 확인 | "예약"만 꺼져 있음(원인 아님) |
| Graph `/me/events` | 토큰에 Calendars 범위가 없어 403이라 사용하지 못함 |
| Calendars.Read를 동의한 토큰으로 달력 조회(`GET /me/calendar`) | 200 OK, 달력 소유자는 사용자 계정(조회). 이 조회로 확인한 것은 달력 소유자까지이고 사라진 원인은 확인하지 못함 |

- **확인 불가**: 일정이 사라진 원인. 시도: 주·월 보기, 일정 검색, 필터 확인, 캘린더 읽기 범위를 동의한 토큰으로 달력 조회. 사유: 화면과 검색에 일정이 없고, 지운 작업을 한 기록도 없어 원인을 좁힐 단서가 없음. 다음 방법: 같은 일이 생기면 일정을 만든 직후 화면을 남겨 두고, Calendars.Read를 동의한 토큰으로 일정 목록을 제목으로 조회해 비교.

### 4. 대처·원복

원인을 모른 채 "원래 있었다"고 쓰지 않고, 같은 이름·같은 시각으로 GUI에서 다시 만들어 그 경위를 남겼습니다.

**GUI 경로**: Outlook 웹 → 캘린더 → 새 이벤트 → 제목 `zz-test-personal-event`, 날짜 2026-10-28, 시작 오전 10:00(끝 10:30) → 저장 → 주 보기에서 확인.

![개인 일정 만들기]({{ "/assets/images/2026/10/m03-3a-personal-event-create.png" | relative_url }})
*그림 1. Outlook 웹에서 개인 일정을 만드는 화면. 제목 zz-test-personal-event, 2026-10-28 오전 10:00~10:30을 넣고 저장 직전.*

![개인 Outlook 캘린더]({{ "/assets/images/2026/10/m03-3-personal-calendar.png" | relative_url }})
*그림 2. Outlook 웹의 관리자 개인 캘린더(10/25~10/31주, 다시 만든 뒤 촬영). 10/28(수) 10:00에 개인 일정 zz-test-personal-event만 있고, 팀 일정을 넣었던 10/27(화) 10:00 칸은 비어 있다. 팀(그룹) 캘린더에 넣은 일정이 개인 캘린더에 보이지 않는다는 점은 이 화면과 팀 캘린더 목록 조회로 함께 확인한다.*

### 5. 운영에서는 이렇게 판단한다

- 만들어 둔 항목이 사라졌는데 원인을 모르면, **원인을 추정으로 채우지 않고** 확인 불가로 기록한 뒤 다시 만든 경위를 남깁니다.
- 증거로 쓸 화면은 **만든 직후에 선명하게** 남겨 둡니다. 나중에 같은 화면을 다시 찍으려다 항목이 없어질 수 있습니다.
- 시험용 일정은 정리 목록에 넣어 둡니다.
