## 비공개 자료 분류
외부에 공개하면 안 되는 자료(플랫폼 구조 지도, 업무 양식, 워크북 등)는 **이 저장소 폴더 안에 아예 두지 않습니다.** 사이트 폴더 밖(예: 별도 `private/` 폴더)에 보관하고, 업로드할 때는 이 폴더의 내용만 올립니다.

주의: 저장소가 공개(public)이면 올라간 파일은 **주소를 아는 누구나 받을 수 있고**, 지운 뒤에도 커밋 기록에 남습니다. `.gitignore`와 `_config.yml`의 `exclude`는 **웹 화면에서 파일을 끌어다 올리는 방식에서는 보호가 되지 않습니다.** `.gitignore`는 점(.)으로 시작하는 파일이라 웹 업로드에서 빠지기 쉽고, `exclude`는 사이트 주소에서만 숨길 뿐 저장소 파일은 그대로 공개되기 때문입니다. 올리기 전에 업로드 목록에 `.pdf`, `.xlsx`, `.docx`, `_private/`가 없는지 확인합니다.

## 표 작성 주의
표(`| 항목 | ... |`) **바로 위에는 반드시 빈 줄**을 둡니다. 제목 줄이나 문장 바로 다음에 표를 붙이면 이 사이트에서는 표로 인식하지 못하고 `|` 글자가 그대로 보입니다.

## 숨김 글과 목차
- 글 상단 머리말에 `published: false`를 넣으면 사이트(목록·검색·주소)에서 사라집니다. 저장소 파일은 남으므로 비밀 내용에는 쓰지 않습니다(비밀은 `_private/`).
- 글 제목 앞에는 순서 번호(00, 01, …)를 붙이고, 새 글은 `_pages/readiness.md` 목차 표에 같은 번호로 추가합니다.
