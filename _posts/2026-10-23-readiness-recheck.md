수행일은 2026-10-23(금)입니다. 10/22까지 "확인 불가"로 남긴 항목은 대부분 "메뉴는 열 수 있었는데 시도하지 않은 것"이었습니다. 그래서 개발용 샌드박스(개인 환경)에서 **삭제와 비용이 드는 일을 뺀 변경은 직접 해 보는 방식**으로 다시 확인했습니다.

> 근거 표기: **조회** = 이 테넌트 화면·PowerShell에서 직접 읽은 값 / **문서** = Microsoft Learn / **확인 불가** = 시도했으나 확인하지 못함(시도 방법·사유 병기). 테넌트 ID·구독 ID·도메인·계정·사용자 이름은 게시하지 않았습니다.

## 1. 이 글의 규칙

"확인 불가"는 **빈칸이 아니라 기록**입니다. 확인하지 못한 항목에는 아래 세 가지를 반드시 함께 적습니다.

1. 시도한 방법
2. 막힌 이유
3. 다음에 확인할 방법(또는 질문으로 남김)

이렇게 적어 두면 이후에 다른 사람이 같은 방법을 반복하지 않고, 막힌 이유를 풀어서 다시 시도할 수 있습니다.

## 2. 변경한 것 (4건)

| 변경 | 내용 | 원복 방법 |
|---|---|---|
| Planner 계획 생성 | Plan MC-Tracking, Bucket MC-Bucket-01 생성 성공 | 팀을 삭제하면 함께 삭제됨(삭제는 본인 수행) |
| 리소스 공급자 등록 | Microsoft.OperationalInsights, Microsoft.Insights를 Registered로 | 구독 > 리소스 공급자에서 등록 취소(선택, 비용 없음) |
| 시험 사용자 부서 변경·원복 | 부서 변경 → 동적 그룹 가입 → 원복 (원복 10:12, 감사 로그) | 이미 원복함 |
| 시험 파일 업로드 | 채널 파일 폴더에 zz-test*.txt 추가 | 팀 삭제 시 함께 삭제 |

삭제는 영구 삭제에 해당해 하지 않았고, 정리 목록에 올려 본인이 진행합니다.

## 4. 끝내 확인하지 못한 것 (시도 방법 · 사유 · 다음 방법)

| 항목 | 시도 방법 | 막힌 이유 | 다음 방법 |
|---|---|---|---|
| Exchange PowerShell | `Connect-ExchangeOnline` 장치 코드 로그인 | 보안 기본값 때문에 AADSTS530035로 차단. 보안 기본값 변경은 보안 설정 변경이라 하지 않음 | 결정권자 확인 후 다른 로그인 방식 검토([05 글]({{ "/m365/troubleshooting/aadsts530035-device-code/" | relative_url }})) |
| 청구 계정 유형·청구 역할 | 청구 범위 조회 | 청구 범위가 0건. 역할을 부여받는 것은 보안 변경이라 하지 않음 | 청구 담당자에게 확인 |
| Log Analytics 작업 영역 생성 | (공급자 등록까지만 함) | 작업 영역 생성은 비용 항목이라 하지 않음 | 비용 허용 여부 확인 후 시도 |
| 조건부 액세스 Workbook | (작업 영역이 필요) | Log Analytics 작업 영역이 없음 | 위 작업 영역 생성 후 |
| 끈 뒤 루트 역할 할당 제거 | 끈 뒤 루트 역할 목록 조회 | 목록 자체가 열리지 않음(권한 없음). 대체 근거로 "권한 없음" 안내 복귀 + 감사 로그 사용 | 켠 상태에서만 목록을 볼 수 있어 직접 확인 방법 없음 |
| MFA 실제 로그인 동작 | 로그인 프롬프트 확인 | 본인 계정의 인증 정보 입력이 필요해 대행하지 않음 | 본인이 직접 로그인해 확인 |
| 비상(break-glass) 계정 | 사용자 목록 확인(없음) | 계정 생성은 하지 않음 | 결정권자 확인 후 생성 |
| 구독 Owner 서비스 사용자의 용도 | 서비스 사용자 상세 열기 | 설명 항목이 비어 있음 | 계정 소유자에게 확인 |
| 1:1 채팅 파일·회의 녹화 저장 위치 | OneDrive 열기, Graph `/me/drive` 조회 | 관리자 OneDrive가 만들어져 있지 않음(기본 문서 라이브러리 오류), 조회 HTTP 403. 녹화는 마이크·카메라가 필요 | 사용자 OneDrive 생성 후 / 사람이 회의를 열어 녹화 |
| 10/22 Planner가 꺼져 있던 원인 | Entra 감사 로그 활동 필터 | 필터 적용 버튼이 활성화되지 않아 10/22 10:3x 항목을 찾지 못함 | 감사 로그를 날짜·시각 범위로 다시 조회 |

## 5. 정리 후 확인

삭제(팀, 리소스 그룹, 시험 파일 등)는 본인이 진행합니다. 삭제가 끝난 뒤 재조회한 결과(Entra 그룹, Teams, 리소스 그룹 수)를 이 글에 한 줄 추가할 예정입니다.
