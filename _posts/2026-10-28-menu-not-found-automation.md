> 근거 표기: **조회** = 실제 포털 화면에서 직접 확인한 값 / **문서** = Microsoft Learn / **확인 불가** = 시도했으나 확인하지 못함(시도 방법·사유·다음 방법 병기). 계정·테넌트 식별자는 적지 않았다.

## 요약

| 항목 | 내용 |
|---|---|
| 증상 | 화면을 자동으로 누르며 경로를 확인하는 도구가 일부 항목에서 "메뉴를 찾지 못함"으로 끝남 |
| 먼저 나눈 것 | (1) 메뉴가 **정말 없는가**, (2) **이름이 달라** 못 찾았는가, (3) 메뉴는 있는데 **조작이 실패**했는가 |
| 판단 | 확인한 범위에서는 (1) 정말 없음은 없었고, 대부분 (2)와 (3) |
| 대처 | 실제 포털에서 경로를 손으로 따라가 화면 이름을 기록하고, 도구에는 이름 별칭과 조작 보강을 반영 |
| 결과 | **조회**: 모의 화면에서 4개 항목 재시험 통과. 실제 포털 전체 재실행은 **확인 불가**(시도: 모의 화면 시험 / 다음 방법: 수정판으로 재실행해 결과 대조) |

## 전체 기록

### 1. 증상

82개 항목의 화면 경로를 자동으로 따라가는 점검이 중간에 멈추고, 일부 항목은 "메뉴를 찾지 못함"으로 기록됐습니다. 실행이 51번째 항목쯤에서 멈춘 이유는 로그에 남지 않아 **확인 불가**입니다. 멈춘 지점부터는 이어서 실행하는 옵션으로 다시 시작할 수 있습니다.

### 2. 먼저 확인할 것

"못 찾음"을 세 가지로 나눕니다. 나누지 않고 "메뉴가 없다"고 적으면 틀린 결론이 됩니다.

| 분류 | 확인 방법 | 이번에 확인한 예 |
|---|---|---|
| 정말 없음 | 사람이 같은 경로를 손으로 따라가 본다 | 없음(확인한 범위에서) |
| 이름이 다름 | 화면의 실제 이름을 기록해 안내 문구와 비교 | 아래 표 |
| 조작 실패 | 메뉴는 보이는데 클릭이 다른 곳에 가거나 가려짐 | 아래 목록 |

### 3. 시도와 결과

**이름이 달랐던 것(조회)**

| 안내 문구 | 실제 화면 |
|---|---|
| 보고서 > 사용량 | 보고서 > **사용 현황** |
| 외부 공동 작업 설정 | **외부 협업 설정** |
| Teams 관리 센터의 메뉴 | 한국어 화면이어도 메뉴 이름이 **영어** |
| Connect Health | 왼쪽 메뉴가 아니라 동기화 연결 화면 안의 **"Microsoft Entra Connect 상태" 링크** |
| 모든 애플리케이션 | 메뉴가 아니라 화면 안의 **탭** |

**메뉴는 있는데 조작이 실패한 것**

- 메뉴 글자 앞에 아이콘 글자(눈에 안 보이는 특수 문자)가 붙어 이름 비교가 어긋났습니다.
- 메뉴 옆의 **"고정"(핀) 버튼**을 메뉴로 잘못 눌렀습니다.
- 화면이 스크롤되면서 측정해 둔 좌표가 달라져 엉뚱한 곳을 눌렀습니다.
- 열려 있던 창(패널)이 메뉴를 가렸습니다.
- 홈 화면에 "Teams"라는 글자가 여러 곳에 있어 다른 요소와 일치했습니다.

**대처**

1. 이름을 비교할 때 아이콘 글자와 보이지 않는 문자를 지우고 공백을 정리합니다.
2. "고정"·"즐겨찾기" 같은 보조 버튼은 후보에서 뺍니다.
3. 누르기 직전에 좌표를 다시 재고, 그 위치에 **정말 그 메뉴가 있는지** 확인한 뒤 누릅니다. 실패하면 요소를 직접 누르는 방법으로 바꿉니다.
4. 저장·삭제 확인 창이 아닌 열린 창은 닫고 다시 시도합니다.
5. 안내 문구와 실제 이름이 다르면 결과에 "문구 → 화면 이름"을 함께 기록합니다.

모의 화면(실제 관리 센터와 비슷한 가짜 페이지)에서 4개 항목을 다시 돌려 모두 통과했습니다(조회). 실제 포털 전체 재실행은 아직 하지 않았습니다.

### 4. 대처와 원복

- 포털 설정은 바꾸지 않았습니다. 화면을 열어 보기만 했고, 열어 둔 설정 창은 저장하지 않고 닫았습니다.

### 5. 운영에서는 이렇게 판단한다

1. 자동 점검이 "못 찾음"이라고 해도 **없다고 결론내리기 전에** 사람이 한 번 따라가 봅니다.
2. 안내 문서의 메뉴 이름은 화면과 다를 수 있으니, 실제 화면 이름을 결과에 같이 남깁니다.
3. 클릭 자동화는 "이름이 보이는가"보다 "그 위치에 그 요소가 있는가"를 확인한 뒤 누릅니다.
4. 도구가 중간에 멈추면 처음부터 다시 돌리지 말고 멈춘 곳에서 이어서 실행합니다.
